Command: launch the local synthetic fixture with `CPS_LOCAL_MODEL_COUNT=200 node .trellis/tasks/09-25-whole-service-performance/research/browser-fixture.mjs`, then for each `0`, `3`, `10` run `python3 .trellis/tasks/09-25-whole-service-performance/research/browser-provider-density.py http://127.0.0.1:<printed-port>/ <count>` twice. The script accepts only an exact loopback URL, logs into the native admin console with the test-only fixture, then intercepts **only** authenticated `/api/statistics` in the local browser and expands each of its 200 model rows with bounded synthetic Provider projections. No production API, credentials, paid upstream or persistence changes. The same production inline UI code renders a 390 CSS px Chromium 145 window; `Performance.getMetrics` captures browser `TaskDuration` and layout time.
