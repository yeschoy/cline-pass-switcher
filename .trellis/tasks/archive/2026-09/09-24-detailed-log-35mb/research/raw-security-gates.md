This is local implementation authorization, **not** authorization to enable raw capture in production.
- `lib/detailed-log-capture.js` currently caps `BodyCapture` at 5 MiB, charges twice retained bytes against a 64 MiB process-wide `CaptureBudget`, and runs group-wide `DetailRedactor` discovery/materialization. The 512 MiB replacement is a reservation ceiling, **not** an RSS/heap promise. Full roots include client input/output plus each upstream attempt input/output; error-only roots publish failed attempt response bodies and hold request source only for credential discovery. Raw mode should retain both request and response bodies only for failed attempts, with no success-body leak from error-only mode, and keep one capture/store owner.
- `lib/detailed-log-store.js` serially publishes text bodies under UUID directories, uses max 5 MiB descriptor/read checks, 1 GiB disk capacity, 7-day age, metadata-only inventory and on-demand body reads. Raw and sanitized must use the same store owner/queue, with raw groups in an isolated child directory and **per-group** 48h vs 7d TTL. A distinct raw manifest profile (`raw-full` / `raw-error`) is deliberately rejected by the previous shared-key validator (which accepts only `full` / `error`), including raw bodies smaller than 5 MiB; this is a rollback read fence. During an actual rollback, ingress must additionally isolate old management and raw files must remain inaccessible. Corrupt/unknown operator-owned groups are preserved by existing safety policy, so the new raw-only private child directory must encode an immutable group timestamp and enforce 48h deletion even when an owned group's manifest is corrupt. Service ownership requires strict directory syntax, only regular allowlisted files and no symlinks; unknown/suspicious entries stay inaccessible, undeleted and visible in safe health for manual remediation. Do not claim the TTL erases external backups or unknown operator files.
- Raw-body text policy: preserve exact valid UTF-8 bytes up to the cap (even if JSON/SSE is incomplete), mark truncation/interruption explicitly; invalid UTF-8 is omitted with an explicit state rather than replacement-character corruption or accidental HTML rendering. The model transport still receives original bytes. Browser uses on-demand `text/plain`, `textContent`/textarea, no automatic body load and clears loaded raw text on navigation/selection/logout.
- Header/list/manifest metadata must be a fixed bounded safe projection when raw capture is enabled: omit Header values and arbitrary account/name/provider/URL text unless independently proven safe without scanning the 35 MiB body. The body itself can contain any credential by explicit exception. Sanitized legacy mode retains its existing group-wide discovery and 5 MiB body/7-day behavior; ordinary JSONL/metadata/services never gain raw body/Header content.
