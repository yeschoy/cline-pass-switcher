The newly implemented monthly statistics UI correctly treats a recent successful monthly-only snapshot as diagnostic, not routing-fresh. With quota routing disabled, simply calling `requestQuota(id,{routingEpoch})` is cancelled. Force requests still respect per-account failure backoff and account credential/proxy generation fences.

New manual-release ban fields cannot be lost on this path (or by ordinary rule recovery), while stale pending refresh/short-window facts must be fenced appropriately. Compare the reference month remaining against $0.20 with a strict boundary and floating-point equality tolerance; a 99.6%-used $50 reference month is **equal** to $0.20 and must not ban.
