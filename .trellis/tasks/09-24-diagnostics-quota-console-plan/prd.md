# 诊断容量、额度可靠性与管理台统计安全改造

## Goal

统筹五项独立交付：详细日志容量、账号额度显示、额度不足时防重复失败、模型/渠道统计页、网页管理登录与 API 密钥分离。父任务管理需求来源、子任务边界和最终集成验收；不直接实现业务功能。

## Source and confirmed facts

- 本次对话先提出将详细日志可记录正文提高到 35 MB，随后明确同意建立 Trellis 并追加四项需求；用户后续明确不是取消 35 MB，而是希望对**单独启用的原文正文模式**取消脱敏工作并把共享诊断保留预算从 64 MiB 提高到 512 MiB；用户已明确允许在生产落盘未脱敏的请求/响应正文并由远程管理员查看；这有意替换当前详细日志安全合同，但只覆盖正文；用户确认 Header 和列表元数据仍保护敏感值，普通日志和配置也不放宽；新未脱敏正文保留 48 小时，旧脱敏记录维持旧规则。**独立管理员认证及首次强制改密必须先交付，原始正文功能保持默认关闭，规划评审前不实施。**
- 第一张截图是第三方对 Cline Pass 5 小时约 $10、每周约 $25、每月约 $50 的社区推算，不是已核实的上游绝对金额承诺。实施前上游额度快照只解析三种窗口的 `percentUsed` 和可选 `resetsAt`（`server.js:914-943`）。用户已确认采用这三个参考上限折算美元等值，明确标示估算；月余额与三窗口中立即可用的估算额须分别展示。
- 第二张截图指定在顶层导航右侧增加“模型和渠道”页面；实施前导航与“统计”页在 `public/index.html:124-151`。用户确认计费需求为记录明确 Token usage，按 ClinePass 官网模型参考单价估算 **“参考用量等值（USD），非实际扣费”**；不是从订阅窗口或社区额度反推出实际账单。
- 实施前控制台从 `localStorage.cps_key` 读取共享代理密钥并用 `X-Admin-Key` 调用管理 API（`public/index.html:381-405`）；`server.js:1789-1801,4090-4102` 用同一 `PROXY_KEY` 同时鉴权管理与模型流量。用户选择独立单管理员密码，初始值为当前代理 API key，**首次登录必须强制改密**且改密前不能访问其他管理 API；之后管理员密码和客户端 key 独立。用户不接受首次改密仅限服务器本机/受信运维通道，确认远程首登需当前代理 API key ＋独立一次性初始化码，再强制改密；正常升级/重启不重复初始化，只有重置/状态丢失走恢复。

## Child map and acceptance

1. `09-24-detailed-log-35mb`：规划 35 MB 正文上限、512 MB 共享预算和生产未脱敏正文的受控保存/远程查看；**依赖先完成 `09-24-separate-console-login`**，不得让旧客户端 key 读明文，业务流量不得受诊断影响。
2. `09-24-monthly-quota-statistics`：准确区分月剩余额度与当前三层窗口可用量，补齐统计页展示。
3. `09-24-quota-exhaustion-protection`：避免账号额度不足时周期性失败风暴，仍可安全恢复。
4. `09-24-model-provider-statistics`：导航增加页面，按模型/渠道展示成功率、缓存、Token 与可解释的费用。
5. `09-24-separate-console-login`：网页管理员登录与客户端 API key 分开，不能互相取得管理权限。

## Cross-child acceptance

- 五项各自有独立的 PRD、设计、实施与测试门禁；父任务待所有子任务验收后才做跨功能回归。
- 额度显示不自动更改路由；新增主动账号封禁不复用可配置错误规则作策略开关，额度不足信号触发已有额度 owner 的去重刷新及有上限的临时暂停，仅在上游额度不足状态码、正文条件与刷新后可信月余额低于阈值三项同时满足时持久封禁；阈值默认每账号参考月余额 $0.20 等值、可在管理页调整，且不依赖页面在线；月额度持久封禁不会因冷却到期、额度刷新/月重置或重启自动解除，允许管理员显式手动解封；5h/周的临时额度阻塞在预计重置后，须由**新鲜成功额度快照确认 5h、周、月全部可用**才自动重入；5h 有额度但周已耗尽、或仅某个窗口重置时不能放行，且不会清除月额度持久封禁。未知用量不冒充 0，费用不凭空计算，HTTP 200 / 成功与诊断丢弃不混淆。
- **本次授权例外仅限独立管理员在生产详细日志中查看有意保存的未脱敏请求/响应正文，可能包含凭据与私人内容**；普通日志、Header/元数据、配置及模型客户端响应不因此放宽。独立管理员登录、页面按需加载、权限与保留安全门禁需先验收；未经单独授权，不连接/修改生产服务、不使用真实密钥做测试、不部署。
